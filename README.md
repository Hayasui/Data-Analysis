# Data-Analysis

本仓库存放定量数据的清洗与分析脚本，以及各份数据对应的值码表。一次投放或一个数据来源占一个
文件夹，文件夹名用批次号；新的分析开新文件夹，不同来源的脚本不混放。

## 目录

```
092601/      一份问卷数据的清洗脚本与分析脚本，以及清洗脚本产出的值码表
```

## 约定

脚本只依赖 Python 标准库，可重跑、跑几次结果都一样。每个文件夹里是一根链条：清洗脚本从原始导出
推到一份一人一行的分析文件，分析脚本只读那份分析文件，出分布表与精度。两者都自带自检，自检不通过
就不写盘；带 `--check` 时只重算并与磁盘上现有的产物逐格比对，不落盘，用来发现脚本与数据之间有没有
走岔。

值码表与分母表由脚本产出，不手工维护——手工维护的表迟早和数据对不上。

原始数据与受访者级数据不入库，`data/` 已在 `.gitignore` 里挡掉。

## 许可

内部分析工具，按需自取。
