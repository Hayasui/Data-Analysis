## 通用码

| 码 | 含义 | 用在哪儿 |
| --- | --- | --- |
| 1 | 选中／确认 | 多选题的每个选项列、二值标记 |
| 0 | 没选／否 | 同上；`what_genre`／`what_rpg` 里的 0 表示一项都没选 |
| 97 | 不适用 | 跳转未出示、门槛过滤、清洗时事后作废的作答；跨批地说，也含「这一批没有这道题」 |
| 98 | 明确表示不愿回答／不便回答 | 问卷里印了这个选项的题：付费与金额四题、性别一题 |
| 99 | 无可用记录 | 整题无数据；开放题没有文本 |
| 自由文本 | 受访者手写的文字 | 开放题列 |

一处例外：性别（S4）的 0 与 1 是两个取值本身（0＝男性、1＝女性），不是「没选／选中」。五个派生标记（`is_mmorpg`、`is_mmorpg_adj`、`play_mmorpg`、`not_mmo_mostplay`、`nested_ok`）都走通用码的 1 与 0。单选与有序题的码（1、2、3……）逐题列在下面。
